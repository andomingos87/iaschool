# Replit Web Cross-Platform Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert this Replit pnpm/Vite workspace into a versioned, reproducible cross-platform web development baseline and use its verified recipe to seed a reusable Replit-web bootstrap skill.

**Architecture:** A read-only preflight first classifies the repository, manager, runtime and native binary restrictions. A pnpm-workspace/Vite recipe then makes only proven configuration changes, while small Node scripts validate native tool loading and a running web server. The repository records the operating contract and GitHub Actions proves it on macOS, Ubuntu and Windows before the recipe is extracted into a reusable skill.

**Tech Stack:** Node.js 24, Corepack, pnpm 11.17.0, pnpm workspaces, Vite 7, React 19, Express 5, TypeScript 5.9, Node built-in test runner, GitHub Actions, in-app browser validation.

## Global Constraints

- Support macOS Apple Silicon and Intel, Linux x64 and ARM64, and Windows x64.
- Keep `.replit` deployment and workflow configuration intact.
- Pin `pnpm@11.17.0` in the root `package.json`; all install and CI commands use Corepack.
- Do not copy, print, commit, or inject values from `.env`, Replit Secrets, browser storage, or shell secrets.
- Do not deploy, publish, migrate a database, change Replit remote configuration, or replace framework/dependency versions.
- Preserve unrelated security overrides; remove only the Replit Linux-only native-binary exclusions identified by preflight.
- Every non-read-only modification begins with a clean `git status` review and stops when it overlaps user-owned work.
- Report local, CI, and Replit-production evidence separately.
