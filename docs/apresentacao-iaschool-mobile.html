Proteção · imagem de menor

Sem autorização, não sai.

POR PADRÃO

O sistema bloqueia.
Não depende de alguém lembrar.

Autorização por aluno, registrada pelo responsável: WhatsApp, rede social — ou nada.

✓ ENVIO

Só para número verificado

Do responsável cadastrado, confirmado por código.

✓ REGISTRO

Trilha de tudo

Quem enviou, o quê, para quem, quando — auditável.

✓ BIOMETRIA

Finalidade única

O dado facial só separa fotos. Nunca perfil, nunca publicidade.

✓ REVOGAÇÃO

Mudou de ideia, saiu do ar

O responsável revoga e o material é retirado.

Base legal: Lei nº 15.211/2025 (ECA Digital) · Decreto nº 12.880/2026 · LGPD, art. 14 Imagem gerada por IA é sempre identificada como tal
